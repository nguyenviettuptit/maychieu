# Máy Chiếu Vật Thể

Ứng dụng web chiếu bài làm của học sinh lên TV / máy chiếu bằng webcam hoặc camera vật thể.

Mở: https://nguyenviettuptit.github.io/appcam/

- Chọn camera, độ phân giải cao nhất (tới 4K), lấy nét tự động / thủ công
- Thu phóng 1×–8× (nút, thanh trượt, cuộn chuột, chụm 2 ngón)
- Xoay 90°/180°/270°, lật gương, lật dọc
- Đóng băng hình, chụp ảnh, chế độ giấy trắng
- Toàn màn hình, thanh công cụ tự ẩn sau 3 giây
- Cài lên màn hình chính như ứng dụng, chạy offline

Phím tắt: Space (đóng băng), F (toàn màn hình), R (xoay), M (lật), +/− (zoom), 0 (khung gốc), S (chụp ảnh).
